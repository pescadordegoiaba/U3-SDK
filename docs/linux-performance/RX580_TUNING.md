# Ajustes RX 580/Polaris

- Caminho padrão usa FP32.
- Não assume ganho de FP16 na Polaris.
- FSR 1 usa passes separados EASU/RCAS e evita CAS simultâneo com RCAS.
- Async compute, VRS, ray tracing, mesh shaders e unidades de IA não são exigidos.
- FSR 4.1 e Frame Generation permanecem indisponíveis.
