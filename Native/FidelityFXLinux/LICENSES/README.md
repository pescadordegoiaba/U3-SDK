# Licenças do Plugin Linux FidelityFX

Este diretório contém apenas a ponte ABI local do U3-SDK nesta etapa.

FSR 1 é implementado no shader Unity do projeto. Código oficial AMD usado como referência deve manter o aviso MIT da AMD quando incorporado.

FSR 2/FSR 3.1 não estão vendorizados nesta revisão porque o backend temporal Vulkan ainda precisa de integração completa com recursos internos da Unity.
